# Boxhead-Style Survival Prototype

A lightweight browser prototype inspired by the Boxhead series. Move a square survivor, shoot incoming zombies from all sides, and grab temporary weapon upgrades.

## How to Run
Open `index.html` in any modern desktop browser. No build tools required.

## Controls
- **Move**: `WASD`
- **Aim**: Mouse
- **Shoot**: Left click or `Space`

## Gameplay Notes
- Enemies spawn from all edges and gradually get stronger.
- Weapon crates drop periodically; collect them to receive an assault rifle or shotgun for a short duration.
- Track health, score, and upgrade timer in the HUD.
